# 残响之庭 · ECHO GARDEN

《残响之庭》v0.9.1 浏览器试玩版与 Android 安装包。

网页入口：https://aqiao021.github.io/canxiang/

运行方式：通过 HTTP(S) 访问本站；本地可使用 `python -m http.server 8765`，然后访问 `http://localhost:8765/`。不支持直接双击 HTML 文件。

网页版使用 Godot 4.6.3 Compatibility 单线程导出，提供单机试玩、教学和机器人对战。浏览器不支持现有 UDP / ENet 局域网联机；联网功能请使用 Android 版本。
